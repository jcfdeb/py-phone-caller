Decentralized Capabilities & Transports

Engineered from first principles for mission-critical reliability, air-gapped field kits, and sovereign crisis networks.

⚡
0xChat & Embedded Nostr Relay
Zero-dependency embedded WebSocket Nostr micro-relay on port 8088. Implements NIP-01/11/20 with SQLite event indexing. Supports NIP-17/59/44 onion gift wraps (ChaCha20-Poly1305) and legacy NIP-04. Features interactive Command & Control (C2) and thread-aware alert acknowledgments (ACK).
NIP-17 NIP-44 NIP-59 0xChat C2 Native TLS
📶
BitChat BLE Offline Mesh
Direct peer-to-peer communication via Linux BlueZ D-Bus peripheral GATT services, bypassing ISPs, cell towers, and internet backbones. Direct messages are secured with the Noise_XX_25519_ChaChaPoly_SHA256 handshake, automatically escalating private emergencies to the public mesh and telephony.
Noise XX BlueZ GATT Zero Internet Ad-Hoc Mesh
📻
Heterogeneous Peering & LoRa RF
Connects field nodes across LoRa serial radios, LAN Ethernet, and WireGuard tunnels. Dynamic distance-vector routing with split-horizon loop suppression. Features an integrated regulatory airtime limiter tracking the 1.0% ETSI EN 300 220 ceiling, backed by persistent SQLite flash-spool storage.
LoRa SLIP ETSI 1.0% Distance-Vector SQLite Spool
📱
Cellular SMS Hardware Bridge
Direct serial AT interface to GSM/LTE cellular modems (SIMCOM, Quectel). Features bi-directional UCS-2 hex and ASCII transcoding for international alphabets and emergency emojis. Hot-reloadable authorized sender ACLs and SQLite audit history prevent unauthorized alert injection.
AT Serial UCS-2 Hex Sender ACL SMS Egress
💻
Tactical Mission Control NOC
Single-page glassmorphic dashboard embedded directly in the binary. Live Server-Sent Events (SSE) telemetry every 2s, Day/Night theme engine for field sunlight readability, synthesized Web Audio alarms (muted by default), active strobe incident banner with 1-click ACK, and an interactive streaming log console.
Live SSE Day/Night Mode Web Audio API Log Terminal
🛠️
Operational Tooling & Config Editor
1-to-1 operational tooling available via terminal CLI or in-browser. BIP-340 Secp256k1 keypair generator, Bech32 npub/nsec translator, SMS UCS-2 codec, SHA-256 hasher, and 256-bit PSK generator. Includes an in-dashboard TOML config editor with dry-run validation and automatic .bak backups.
Keygen Bech32 TOML Editor Dry-run Check

Cloud-Native Layered Configuration
Strict parity with py-phone-caller's Python Dynaconf engine powered by Rust's config crate. Multi-tier precedence supports static TOML files, turnkey deployment profiles (edge-sensor, mesh-repeater, central-gateway), and 12-Factor container environment overrides (OPENALERT_<SEC>__<KEY>). Enables pure ephemeral container execution with zero disk mounts.

Quickstart & Building `openalertd`

Compiled with standard Rust tooling. Produces a single static executable with zero shared library or package dependencies. 

# 1. Clone the repository
git clone https://github.com/jcfdeb/py-phone-caller.git
cd py-phone-caller/src/openalert

# 2. Run the comprehensive test suite (47 unit + 45 integration tests)
cargo test

# 3. Build optimized release binary
cargo build --release

# 4. Launch with turnkey profile
./target/release/openalertd config/profiles/central-gateway.toml

Operational CLI Commands

# Validate configuration syntax and active directories
openalertd check-config config/openalertd.toml

# Generate a full Nostr Secp256k1 identity (nsec, npub, and ready-to-paste TOML)
openalertd generate-keypair

# Convert 0xChat mobile npub or nsec into hex (and auto-derive pubkeys)
openalertd convert-key npub1uvtjer4wn7y2qpe4clvqd7qz7x483pthpngewqddc03xes39uq3sw9p5u6

# Transcode cellular SMS UCS-2 hex and international text
openalertd convert-sms "Critical alert ⚠️"

# Generate secure SHA-256 password hash for Web UI authentication
openalertd hash-password "yourTacticalPassword"

# Inspect live daemon status, peering links, and persistent spool
openalertd status
openalertd peers
openalertd spool
